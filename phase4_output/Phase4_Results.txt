        : Predictions land in 3 of 10 confidence bins ([0.3, 0.4), [0.4, 0.5), [0.5, 0.6));
          per-bin counts → [0.3, 0.4): n=53, [0.4, 0.5): n=22, [0.5, 0.6): n=16.
        : DECISION-RULE NOTE — the argmax rule selected A1 on ALL 91 files, so
          decision accuracy coincides with the always-A1 baseline. The network’s value
          is in the calibrated CONFIDENCE, not in flipping the hard label: files whose
          sensors all fire (TTTT) are predicted with ~58% confidence and are ~62.5%
          accurate, while no-evidence (FFFF) files get ~38% confidence and are ~36%
          accurate — the probability spread tracks reality even though the argmax label
          does not move. This is exactly what the reliability diagram visualises.
Caveats :
  1. With 91 files and argmax posteriors that cluster in few bins, the 10-bin
     reliability estimate is coarse — each populated bin averages only 30.3 files.
  2. In-sample protocol: CPTs were learned from these same files, so these numbers
     characterize the engine’s evidence channel on the benchmark, not generalisation.
  3. The Brier score is reported for the full posterior (multiclass) and for the
     argmax prediction (top-label); both are proper scoring rules — lower is better.
  4. A low ECE with a narrow confidence range means the engine is honest *within*
     that range only; see the reliability diagram for the visual check.
