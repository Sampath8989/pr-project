# Who&When benchmark data source

This folder contains the 184 public Who&When failure traces used by AgentDiag v2. The dataset was published with the paper “Which Agent Causes Task Failures and When? On Automated Failure Attribution of LLM Multi-Agent Systems.”

- Paper: https://arxiv.org/abs/2505.00212
- Upstream benchmark repository: https://github.com/ag2ai/Agents_Failure_Attribution
- Upstream dataset card: https://huggingface.co/datasets/Kevin355/Who_and_When
- The adjacent LICENSE file is copied from the upstream repository.

AgentDiag v2 analyzes these saved traces; it does not run or reproduce the original agent systems.
